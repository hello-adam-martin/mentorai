# Audit

Every action is logged with its reasoning, retained, and explainable in plain language.

| requirement | value |
| --- | --- |
| log all actions | true |
| require reasoning (which objective + why) | true |
| retention | 365 days |
| human-reviewable | true |

Explainability is first-class: a decision that can't be explained to a responsible human is a
governance failure.
